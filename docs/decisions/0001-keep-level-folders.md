# 0001: Keep code, task files and results in the level folders

Date: 2026-11-08. Status: accepted.

## Context

The portfolio standard v2 lays a repo out as src/, experiments/ and
results/, and allows domain-named code folders when the README layout
table lists them. This repo's code, task files and results live in
level-1-learn/, level-2-build/ and level-3-deep/. Their paths are
baked into the runners, the tests, the Deep code scanner (which reads
level-2-build/eval_suite.py), the dashboard's build-time imports, the
JavaScript replay check, and the CI step that fails when a committed
results file differs from a fresh run.

## Decision

Keep the three folders and their files where they are. The README
layout table maps them to the standard's roles: code (*.py), evidence
inputs (tasks_*.json, whose SHA-256 values are recorded in
results_build.json), and results (results_*.json, regenerated by one
command each and checked in CI). Only the level READMEs moved, into
REPORT.md.

## Consequences

No recorded path, hash or result changes, so the migration cannot
silently alter evidence. The folder names still read as the old
ladder; a later rename to src/, experiments/ and results/ is one
mechanical pull request that must update every path listed above
together.
